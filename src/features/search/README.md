# 공개 상품 검색 (메인 `/`) — 설계 기록

명세에는 **없는 화면**이다. 로컬 테스트에서 나온 요구다 — 사업장 홈(`/@{slug}`)은 주소를 아는 손님만 닿으므로
상호를 모르면 아무것도 찾을 수 없었고, 서비스에 처음 온 사람이 보는 것이 로그인 폼이었다.

```
features/search/visibility.ts  공개 여부를 SQL 로 쓴 판정 (공개 홈 게이트의 두 번째 표현)
features/search/search.ts      searchProducts · activeCategories
features/search/ui/SearchPanel.tsx  검색 입력 + 결과 목록 (클라이언트)
components/AppHeader.tsx       서비스 헤더 — 로그인 진입이 여기 있다
app/page.tsx                   메인 = 검색
app/me/reservations            로그인한 손님의 예약 내역 (조회만)
```

## 결정한 것

**메인은 검색이고, 로그인은 헤더에 있다.** 둘러보는 것이 먼저다 — 예약할 마음을 먹기 전에 로그인 폼을 만나면
그 자리에서 닫는다. 검색은 **로그인 없이** 된다.

**보이는 범위는 공개 홈과 정확히 같다.** 검색이 더 보여 주면 그게 곧 정보 유출이다 — 심사 중·정지·차단·
내려둔 사업장이 상호와 상품명을 내보내게 된다. 그런데 판정이 두 곳에 생겼다: 공개 홈은 사업장 하나를 읽어
TS 로 보고(`isInfoComplete`), 검색은 여러 사업장을 훑어 자르므로 WHERE 절에 있어야 한다.
**같은 규칙의 두 번째 표현**이라 어긋날 수 있어, `tests/db/search.test.ts` 가 상태를 하나씩 바꿔 가며
두 판정이 같은 답을 내는지 본다(승인 전·정지·차단·반려·임시 slug·정보 미완성·홈 내림·상품 HIDDEN·자원 비활성).

**결과는 상품이다, 사업장이 아니다.** 손님이 고르는 것은 "어디" 가 아니라 "무엇" 이고, 카드를 누르면
가게 홈을 한 번 더 거치지 않고 **바로 예약 단계**(`/@{slug}/book?product=…`)로 간다.

**검색어는 상품명·상호·주소를 함께 본다.** "네일" 처럼 상품으로도, "봄 네일" 처럼 상호로도, "강남" 처럼
동네로도 찾는다. `ilike` 부분 일치뿐이고 형태소 분석·랭킹은 없다 — 사업장이 열 곳일 때 필요한 것은
정확도가 아니라 "있는 게 다 보이는 것" 이다 (`LATER.md` L-45).

**빈 검색어는 필터가 아니다.** 전부 보여 준다. 1기에는 그게 디렉터리 역할을 한다.

**업종 칩은 공개 상품이 있는 업종만 낸다.** 눌러도 빈 화면인 칩을 두지 않는다.
없는 업종 코드가 들어오면 **필터로 쓰지 않는다** — 오타 하나가 빈 화면이 되면 검색이 고장 난 것처럼 보인다.

**검색 상태는 주소에 있다** (`?q=`·`?category=`). 위젯과 같은 이유다 — 컴포넌트 상태로 들면 뒤로가기가
검색을 잃고 결과를 링크로 보낼 수도 없다. 입력 중에는 주소를 건드리지 않고(히스토리가 글자마다 쌓인다)
제출할 때 한 번 바꾼다. 주소가 바뀌면 부모가 `key` 로 리마운트시켜 입력칸이 따라간다 —
effect 로 되돌리면 한 프레임 어긋난 값을 먼저 그린다.

**사업장 홈 상단은 "마주,봄 / 가게" 두 조각이다.** 검색으로 들어온 손님이 여기가 마주,봄이라는 걸 알아야
다른 가게도 찾아보고, 길을 잃었을 때 돌아갈 곳이 있다. 가게 이름 쪽도 링크다 — 예약 화면에서 홈으로 오는 길이 된다.
긴 상호에 브랜드가 밀려 사라지지 않게 브랜드만 폭을 고정했다.

## 내 예약 (`/me/reservations`)

**조회만 한다.** 취소·시간 변경·문의하기는 예약 상세(#89)의 몫이다. 그래서 카드에 **예약번호를 크게** 둔다 —
확정 메일도 "바꾸거나 취소하려면 매장으로 연락, 예약번호를 알려 주세요" 라고 말하고, 손님이 전화로 댈 값이 그것이다.

**지난 시각인데 아직 살아 있는 예약도 "다가오는" 쪽에 둔다.** 어제 다녀온 예약이 `COMPLETED` 로 넘어가기
전까지 목록에서 사라지면 손님은 예약이 없어진 줄 안다. 상태 전이는 매장·배치의 속도에 달렸다.

**시각은 사업장 타임존의 벽시계 문자열로 내린다** (`formatInstant`, 콘솔 목록과 같은 규약).
`Date` 를 넘겨 화면에서 포맷하면 보는 사람의 시계로 옮겨져 매장 시각과 어긋난다.

- **지역·거리 검색** — `businesses.lat/lng` 가 아직 비어 있다 (온보딩이 좌표를 받지 않는다)
- **메인 색인 정책** — 1기 게이트가 `noindex` 라 지금은 의미가 없다. W16 에 게이트를 끌 때 함께 정한다 (L-45)
